# Calcule suas finanças
# 📊 Calculadora de Finanças Pessoais

Um aplicativo web simples e interativo para auxiliar no controle financeiro pessoal, calculando saldos finais e recomendando porcentagens para reserva de emergência.

🚀 **[Clique aqui para testar o aplicativo no celular/navegador]((https://calculatudo.streamlit.app/))**

---

## 🛠️ Tecnologias Utilizadas

- **Python** (Lógica do aplicativo e cálculos)
- **Streamlit** (Interface gráfica e publicação na web)

---

## 💡 Como Funciona

1. O usuário informa o nome, salário mensal, gastos fixos e variáveis.
2. O sistema calcula o saldo restante ao final do mês.
3. É apresentada uma sugestão automática de 20% do valor restante para reserva de emergência e 80% para uso livre.
